# 07 — Lineamientos UI/UX

## Estilo general

La app debe tener un estilo:

- Sobrio.
- Técnico.
- Institucional.
- Profesional.
- Limpio.
- Responsive.
- Orientado a dashboard administrativo.

## Paleta sugerida

```txt
Azul institucional: #0F172A
Azul acción: #2563EB
Gris fondo: #F8FAFC
Gris borde: #CBD5E1
Verde vigente: #16A34A
Amarillo alerta: #EAB308
Naranja crítico: #F97316
Rojo vencido: #DC2626
Azul calibración: #0284C7
Gris sin datos: #64748B
Blanco: #FFFFFF
```

## Estados visuales

| Estado | Color |
|---|---|
| Vigente | Verde |
| Alerta 16-30 días | Amarillo |
| Alerta 1-15 días | Naranja |
| Vencido | Rojo |
| En calibración | Azul |
| Sin calibración | Gris |

## Layout desktop

Usar:

- Sidebar lateral.
- Topbar superior.
- Área de contenido.
- Cards KPI.
- Tablas amplias.
- Formularios en páginas o diálogos grandes.

## Layout móvil

Usar:

- Navegación adaptativa.
- Posible bottom navigation.
- Cards apiladas.
- Tablas simplificadas o listas.
- Acciones en menús contextuales.

## Dashboard

Debe incluir:

- Título claro.
- Resumen KPI.
- Gráfico por estado.
- Próximos vencimientos.
- Vencidos.
- En calibración.

## Inventario

La tabla debe ser clara y legible.

Debe incluir:

- Buscador global.
- Filtros.
- Badges de estado.
- Botones de acción.
- Columna de días restantes.
- Ordenamiento por fecha de vencimiento.

## Formularios

Los formularios deben estar organizados por secciones:

1. Datos generales.
2. Datos técnicos.
3. Ubicación y estado.
4. Calibración.
5. Documentos.
6. Observaciones.

## Detalle de herramienta/equipo

La pantalla de detalle debe mostrar:

- Encabezado con nombre/código.
- Estado visual.
- Datos técnicos.
- Última calibración.
- Ubicación actual.
- Historial de calibraciones.
- Historial de envíos.
- Archivos asociados.

## Alertas

La vista de alertas debe priorizar:

1. Vencidos.
2. Vencen en 1 a 15 días.
3. Vencen en 16 a 30 días.
4. En calibración.
5. Sin calibración.

## Mensajes de usuario

Usar mensajes claros:

- Registro creado correctamente.
- Cambios guardados.
- Certificado cargado.
- Guía de remisión cargada.
- Error al cargar archivo.
- No se encontraron resultados.

## Accesibilidad

- Mantener buen contraste.
- Evitar textos muy pequeños.
- Usar botones distinguibles.
- Usar íconos con texto cuando sea necesario.
